# SQLStructEval project website

This independent `gh-pages` branch contains the static academic project page.
Code and experiment documentation are on [`main`](https://github.com/XanderZhou2022/AACL2026-SQLSTRUCTEVAL/tree/main).

Enable **Settings → Pages → Deploy from a branch → gh-pages → /(root)**.
No Node build, credentials, external fonts or analytics are needed.

For a local preview, run `python3 -m http.server 8000` here, then open http://localhost:8000.
Update `index.html` for text/results and `assets/sqlstructeval-paper.pdf` for the paper.
The provisional BibTeX should be updated once official proceedings metadata is available.

The page uses the authors' supplied academic template, with acknowledgment of Nerfies, Bulma and Font Awesome. See THIRD_PARTY_NOTICES.md. Paper and figure rights remain with their respective rights holders.
